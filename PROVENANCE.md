# Project Provenance

## Project

Agent Skills Compendium

## Original Creator

Jerson Boyd Milan — https://jersonboydmilan.com/

## Initial Development

2026

## Original Project Scope

The project establishes a structured framework for defining, organizing,
discovering, composing, evaluating, governing, and deploying reusable skills
for AI agents.

## Core Original Concepts

- the Agent Skills Compendium
- the five-layer Agent Skills architecture
- the Agent Skills taxonomy
- the standardized skill definition
- skill relationships (prerequisite, complementary, successor, related)
- skill composition
- machine-readable skill definitions
- the agent capability registry concept
