# Authors

## Creator & Principal Architect

**Jerson Boyd Milan**

Jerson Boyd Milan is the original creator and principal architect of the
Agent Skills Compendium.

The original project conception and framework includes the development of:

- the Agent Skills Compendium concept
- the Agent Skills taxonomy (twenty categories)
- the five-layer Agent Skills architecture
- the standardized skill specification
- the skill categorization framework
- the skill relationship model
- the skill composition concept
- machine-readable skill definitions
- the initial compendium information architecture

Website: https://jersonboydmilan.com/
